# Skim: Key Features

- **Voice-to-Text Transcription:** Converts long voice messages into accurate written text.
- **AI Summaries:** Condenses lengthy voice notes into short, easy-to-read summaries.
- **Messaging App Integration:** Works with apps like WhatsApp and iMessage so voice notes are handled where they arrive.
- **Key Detail Extraction:** Automatically pulls out the important details from each message.
- **Date and Deadline Detection:** Finds dates and times mentioned so nothing gets missed.
- **Action Item Capture:** Identifies tasks and things you need to do and lists them clearly.
- **Bullet-Point Formatting:** Turns messy, rambling audio into clean, scannable bullet points.
- **Time Savings:** Saves users about 2 hours of listening each week.
