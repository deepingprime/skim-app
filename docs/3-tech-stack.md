# Tech Stack and Hosting

## Tools and Languages
- **Next.js (React & TypeScript):** This tech stack was employed for building the site and making backend API calls to keep my API keys safe.
- **OpenAI Whisper API:** This API is responsible for converting the uploaded voice note audio to text.
- **OpenAI GPT-4o-mini API:** This API summarizes the generated text in bullet points, including tasks and dates.
- **Tailwind CSS:** Quickly stylizes pages and makes it look good on mobile phones.

## Hosting
The site will be hosted at **Vercel** linked to the current GitHub repository (`github.com/deepingprime/skim-app`). Each time I make commits to the main branch, the deployment will be done automatically by Vercel. As the app is web-based, it will be possible to access the site directly via browser from one's mobile phone or computer.
